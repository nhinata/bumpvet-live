# bumpvet-live

[bumpvet](https://github.com/nhinata/bumpvet) on real Dependabot pull requests.

This repository holds only dependencies: no code. Dependabot proposes their
updates, and bumpvet vets each one. The
[pull requests](https://github.com/nhinata/bumpvet-live/pulls?q=is%3Apr) show
what it says and, for every `REVIEW` or `BLOCK`, what was checked before
merging or closing.
